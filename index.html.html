Quiz 1 — Searching & Queue

Labs 3 & 7/8 2 Questions 10 Marks Total
Question 1  ·  5 marks
Implement binarySearch in Java. The method takes a sorted integer array and a key, and returns the index of the key — or -1 if not found.

Write the full method and test it with the array {10, 25, 30, 45, 50} searching for key 45. Print the result.
✓ Model Answer
public static int binarySearch(int[] arr, int key) { int left = 0; int right = arr.length - 1; while (left <= right) { int mid = (left + right) / 2; if (arr[mid] == key) return mid; else if (arr[mid] < key) left = mid + 1; else right = mid - 1; } return -1; // not found } public static void main(String[] args) { int[] arr = {10, 25, 30, 45, 50}; // sorted int key = 45; int result = binarySearch(arr, key); if (result != -1) System.out.println("Element found at index: " + result); else System.out.println("Element not found"); } // Output: Element found at index: 3 // Time Complexity: // Best Case → O(1) (element at middle) // Worst Case → O(log n) (element not found) // Average Case → O(log n)

Question 2  ·  5 marks
Implement a Queue using an Array in Java. Your myQueue class must support:
enqueue(x) · dequeue() · getFront() · getRear() · isEmpty() · isFull()

In main, create a queue with capacity 3, enqueue 10, 20, 30, print the front — then dequeue once and print the new front and rear.
// Expected output: // Front: 10 // Front: 20 // Rear: 30
✓ Model Answer
class myQueue { int[] arr; int capacity; int size; myQueue(int capacity) { this.capacity = capacity; arr = new int[capacity]; size = 0; } boolean isEmpty() { return size == 0; } boolean isFull() { return size == capacity; } void enqueue(int x) { if (isFull()) { System.out.println("Queue is full!"); return; } arr[size] = x; size++; } void dequeue() { if (isEmpty()) { System.out.println("Queue is empty!"); return; } for (int i = 1; i < size; i++) arr[i - 1] = arr[i]; size--; } int getFront() { return isEmpty() ? -1 : arr[0]; } int getRear() { return isEmpty() ? -1 : arr[size - 1]; } } public class Main { public static void main(String[] args) { myQueue q = new myQueue(3); q.enqueue(10); q.enqueue(20); q.enqueue(30); System.out.println("Front: " + q.getFront()); // Front: 10 q.dequeue(); System.out.println("Front: " + q.getFront()); // Front: 20 System.out.println("Rear: " + q.getRear()); // Rear: 30 } } // Queue is FIFO — First In, First Out. // dequeue() shifts all remaining elements one position left.

Quiz 2 — Sorting & Stack

Labs 4 & 6 2 Questions 10 Marks Total
Question 1  ·  5 marks
Implement Bubble Sort in Java using the optimised version with a swapped boolean flag so it stops early when the array is already sorted.

Test it on the array {5, 1, 4, 2, 8} and print the sorted result using Arrays.toString(arr).
// Trace — Pass 0: // {5,1,4,2,8} → swap 5&1 → {1,5,4,2,8} // → swap 5&4 → {1,4,5,2,8} // → swap 5&2 → {1,4,2,5,8} // Pass 1: → swap 4&2 → {1,2,4,5,8} ✓ done
✓ Model Answer
import java.util.Arrays; public static void bubbleSort(int arr[]) { int n = arr.length; boolean swapped; for (int i = 0; i < n - 1; i++) { swapped = false; for (int j = 0; j < n - i - 1; j++) { if (arr[j] > arr[j + 1]) { int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; swapped = true; } } if (!swapped) break; // already sorted — exit early } } public static void main(String[] args) { int arr[] = {5, 1, 4, 2, 8}; bubbleSort(arr); System.out.println("Sorted array:"); System.out.print(Arrays.toString(arr)); } // Output: // Sorted array: // [1, 2, 4, 5, 8] // Time Complexity: // Best Case → O(n) (already sorted, swapped stays false) // Average Case → O(n²) // Worst Case → O(n²)

Question 2  ·  5 marks
Implement a Stack using an Array in Java. Your Stack class must have a fixed size of 3 and support:
push(value) · pop() · isEmpty() · isFull() · print()

push must print "Stack Overflow" when full. pop must print "Empty Stack" when empty.

In main: push 5, 4, 10 → print the stack → pop twice → print again.
// Expected output: // 5 pushed into stack // 4 pushed into stack // 10 pushed into stack // Stack have: 10 4 5 // ******** // 10 removed from stack // 4 removed from stack // Stack have: 5
✓ Model Answer
public class Stack { int size = 3; int top = -1; int a[] = new int[size]; public void push(int value) { if (isFull()) System.out.println("Stack Overflow"); else { top++; a[top] = value; System.out.println(value + " pushed into stack"); } } public void pop() { if (isEmpty()) System.out.println("Empty Stack"); else { int v = a[top]; top--; System.out.println(v + " removed from stack"); } } public boolean isEmpty() { return (top < 0); } public boolean isFull() { return (top >= size - 1); } public void print() { System.out.println("Stack have:"); for (int i = top; i > -1; i--) System.out.println(a[i]); } } public class Test { public static void main(String[] args) { Stack s = new Stack(); s.push(5); s.push(4); s.push(10); s.print(); System.out.println("********"); s.pop(); s.pop(); s.print(); } } // Stack is LIFO — Last In, First Out. // top starts at -1 (empty) and tracks the index of the top element.

Question 1  ·  5 marks
Build a Singly Linked List in Java with a Node class and a LinkedList class.

Implement all of: addHead(value) · addTail(value) · add(value, index) · deleteHead() · deleteTail() · delete(index) · print()

Run the exact sequence below in main and print the final list:
// addHead(10) → [10] // addHead(5) → [5, 10] // addHead(20) → [20, 5, 10] // addTail(50) → [20, 5, 10, 50] // addTail(60) → [20, 5, 10, 50, 60] // add(100, 3) → [20, 5, 10, 100, 50, 60] // deleteHead() → [5, 10, 100, 50, 60] // deleteTail() → [5, 10, 100, 50] // delete(2) → [5, 10, 50] // print() → 5 10 50
✓ Model Answer
class Node { int value; Node next = null; public Node(int value) { this.value = value; } } class LinkedList { Node head = null; public void print() { Node i = head; while (i != null) { System.out.println(i.value); i = i.next; } } public void addHead(int value) { Node newNode = new Node(value); newNode.next = head; head = newNode; } public void addTail(int value) { Node newNode = new Node(value); Node i = head; while (i.next != null) i = i.next; i.next = newNode; } public void add(int value, int index) { Node newNode = new Node(value); Node i = head; for (int count = 0; count < index - 1; count++) i = i.next; newNode.next = i.next; i.next = newNode; } public void deleteHead() { head = head.next; } public void delete(int index) { Node i = head; for (int count = 0; count < index - 1; count++) i = i.next; i.next = i.next.next; } public void deleteTail() { Node i = head, j = head; while (i.next != null) i = i.next; while (j.next != i) j = j.next; j.next = null; } } class TestList { public static void main(String[] args) { LinkedList l = new LinkedList(); l.addHead(10); l.addHead(5); l.addHead(20); l.addTail(50); l.addTail(60); l.add(100, 3); l.deleteHead(); l.deleteTail(); l.delete(2); l.print(); } } // Output: // 5 // 10 // 50

In main, search for key 30 in array {10, 25, 30, 45, 50} using both and print the index each returns.

Also write a comment block explaining: when should you prefer Binary Search over Linear Search, and why?
// Expected output: // Linear Search → Element found at index: 2 // Binary Search → Element found at index: 2 // Key difference: // Linear → works on unsorted arrays, O(n) // Binary → requires sorted array, O(log n) — much faster for large data
✓ Model Answer
public static int linearSearch(int[] arr, int key) { for (int i = 0; i < arr.length; i++) { if (arr[i] == key) return i; } return -1; } public static int binarySearch(int[] arr, int key) { int left = 0, right = arr.length - 1; while (left <= right) { int mid = (left + right) / 2; if (arr[mid] == key) return mid; else if (arr[mid] < key) left = mid + 1; else right = mid - 1; } return -1; } // When to prefer Binary Search over Linear Search? // ───────────────────────────────────────────────── // Use Binary Search when: // 1. The array is SORTED. // 2. The dataset is LARGE — e.g. for 1,000,000 elements: // Linear takes up to 1,000,000 steps → O(n) // Binary takes only ~20 steps → O(log n) // // Use Linear Search when: // - The array is unsorted. // - The dataset is very small (overhead not worth it). public static void main(String[] args) { int[] arr = {10, 25, 30, 45, 50}; int key = 30; System.out.println("Linear Search → Element found at index: " + linearSearch(arr, key)); System.out.println("Binary Search → Element found at index: " + binarySearch(arr, key)); } // Output: // Linear Search → Element found at index: 2 // Binary Search → Element found at index: 2
